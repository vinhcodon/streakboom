# ADR-0017: Settings: a left navigation with one page per section

- **Status:** accepted
- **Date:** 2026-11-08
- **Decided by:** Vinh (author), with Claude

## Context
One long column no longer fit General, Personality, three brains, Memory, Privacy and About.

## Decision
A left column (General, Personality, Brain, Memory, Privacy, About), one page each. General holds language, start with Windows and the update mode.

## Alternatives considered
Horizontal tabs; one column with a jump bar (both declined).

## Consequences and when to revisit
New sections add a page; the window is 680x600.
