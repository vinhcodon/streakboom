# ADR-0019: A four-card first-run tour, replayable from Settings

- **Status:** accepted
- **Date:** 2026-11-08
- **Decided by:** Vinh (author), with Claude

## Context
New users do not know the gestures or that chat needs a key.

## Decision
Four short cards from the pet on a fresh install only; existing users are marked done. The consent card waits for the tour. Replay is in Settings > About.

## Alternatives considered
Silent hints only (kept as a complement).

## Consequences and when to revisit
Never watched by the author in the real window.
