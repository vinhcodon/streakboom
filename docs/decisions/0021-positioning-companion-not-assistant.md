# ADR-0021: The pet is a companion, not an assistant

- **Status:** accepted
- **Date:** 2026-11-08 (from the product discussion in docs/handoff/north-star-bond-days.md)
- **Decided by:** Vinh (author), with Claude

## Context
Assistants sell capability; a pet should sell a relationship: presence, memory, growth, a consistent character.

## Decision
Three-question filter for every feature: (1) can the user do it by prompting another assistant? then do not build it; (2) does it make the pet more attached, more remembering or visibly growing? if not, drop it; (3) with all AI off, is the pet still lovable? if not, it is an assistant in a cat costume. Heavy work belongs to an assistant the user already has.

## Alternatives considered
A chat-first assistant with a face (rejected).

## Consequences and when to revisit
Tension with the original hypothesis H3 (utility over web chat): see docs/hypotheses.
