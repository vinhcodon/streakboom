# Foundation of Streakboom (evidence)

**Home of:** what the research says about attachment, digital companions, addictive design, claims and law, with the confidence of each statement. Added to the documentation map by ADR-0058.

It is not the home of principles (`../charter.md`) or decisions (`../decisions/`). Where it points to a rule, the charter or an ADR decides.

| File | Role |
| --- | --- |
| `streakboom-foundation.vi.md` | The research, in Vietnamese (original) |
| `streakboom-foundation.en.md` | English version, for Product Hunt and partners |
| `charter-alignment.md` | The eleven hard rules mapped against the charter and ADRs: what exists, what is new, what conflicts |
| `legal-questions.md` | Questions for a lawyer before launch |

## How strong is this?

Most sources were read as abstracts or news summaries, not in full; only the Gemini API terms were opened directly. Treat figures as pointers to check, not as verified facts. The foundation says so in its own "scope of confidence" paragraph. It is information, not legal or medical advice.

## Two layers

1. **Normative** (charter, ADR-0056, ADR-0057): mission, 18+, hard rules, banned claims. Changes only by a new ADR.
2. **Evidence** (the two research files and anything added in `evidence/`): changes when better evidence arrives; cite the source and date, update both languages.

## Adding research

Put new studies in `evidence/<topic>.md` with front matter (`status`, `updated`, `confidence`) and a line saying which foundation section it supports or contradicts. If it changes a rule, write an ADR.
