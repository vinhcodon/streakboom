# Names for the dog: five candidates and what a web search found

**Status:** written 2026-11-15 for the handoff `docs/handoff/duo-characters-hypothesis.md`. The author has not chosen. **A web search is not a trademark search**: it shows what is easy to find, not what is registered; nothing here says a name is free. The rules of the handoff: short, easy to remember, nothing that suggests power ("master"), not a common word, and not Doge, Cheems or Kabosu. Searched on 2026-11-15 with plain web searches only (the name and a word such as dog, character, mascot, brand); nothing about the project was sent.

| Name | What was found | Reading |
|---|---|---|
| **Pidi** | No brand, character or mascot called Pidi turned up in the search of "Pidi" with dog, cartoon, character, mascot. (It may be a common given name in some countries and the search was thin.) | The cleanest of the five in this search; **still to check in a registry** |
| **Rilo** | No app, brand or mascot called Rilo turned up. (Results were generic mascot design pages.) | Clean in this search; **to check in a registry** |
| **Nubi** | A bear character called [Nubi (누비)](https://inabooth.io/en/ip/INB-I3N-RYTT), listed as an original character IP in Korea; US registrations of [NUBI for hair products](https://trademarks.justia.com/866/85/nubi-86685935.html) (Exclusive Label Inc.) and an abandoned application of [NUBI Technologies](https://trademark.trademarkia.com/nubi-86030366.html) for phone accessories; "nubi" also means clouds in some language | Not a dog, but a character IP and registered marks exist: **a risk** |
| **Kopi** | Several dogs are already called Kopi: the sticker set [Kopi the Dog](https://store.line.me/stickershop/product/1039546/en) on LINE, a [Tenor cartoon dog](https://tenor.com/view/smile-kopi-dog-coffee-drinking-gif-16727719), a [Sticker.ly pack](https://sticker.ly/s/9ZX802), and the YouTuber Thinknoodles's dog | **Rejected**: it would collide with existing dog stickers |
| **Dabo** | Mostly the football coach Dabo Swinney (many [stickers](https://www.redbubble.com/shop/dabo+stickers) of him) and meme stickers | **Rejected**: a famous person |

**Recommendation:** Pidi or Rilo as the first choices, after a check in the registries that matter (Vietnam, the United States, the European Union and Japan, and the stores of stickers and apps), and a spoken test (does it sound right in Vietnamese, English and Japanese, and does it have a bad meaning in any of them). Under ADR-0126 no trademark policy protects a name, so a name is only a name: the check is to avoid someone else's, not to protect ours.

**What is not known:** whether either name is registered anywhere; what it means in Vietnamese slang or in Japanese; whether the cleanliness of the search is only because the name is rare in indexed pages.
