A little cat that lives on your screen.

Meet Peak, a cheerful golden chibi cat. It reacts when you stroke, poke or carry it, says short lines in Vietnamese or English, and keeps you company. Free and open source, for Windows.

A companion, not an assistant

Lovable with no AI at all. Bring your own key if you want it to chat.

🐈 Alive without AI

A mood and closeness model, 182 hand-written lines per language, quiet hours, and no guilt: it never dies or starves, it only gets a bit lonely.

👆 Gestures, not buttons

Sweep over its head to scratch, over its belly to rub, click to poke, drag to carry it by the scruff. Its eyes follow your cursor.

🧠 Bring your own brain

Add a Gemini, Claude or OpenAI key and double-click to chat. Gemini has a free tier. Your key stays on your computer.

💭 Remembers a little

A name for the pet, what to call you, a few milestones. See, edit or forget any of it in Settings, Memory.

🤫 Polite

Quiet in fullscreen apps, during quiet hours and in Quiet mode. Never takes keyboard focus for plain speech.

🍃 Light

About 100 to 120 MB of memory and almost no CPU while it stands still (measured on one machine so far).

Install in three steps

  1. Download Streakboom_<version>_x64-setup.exe with the button above, or from the latest release.
  2. Run it. If Windows says "Windows protected your PC", choose More info, then Run anyway. It installs for the current user only, with no administrator rights.
  3. Peak appears on your screen and shows a short tour. To remove it, use Windows Settings, Apps.

Windows needs the WebView2 runtime; the installer downloads it if it is missing.

Your data stays yours

  • API keys are stored in the Windows Credential Manager and sent only to the provider you chose.
  • What Peak remembers is stored on your computer, and you can see or delete all of it in Settings.
  • Usage stats are off by default, and nothing is ever sent automatically.
  • Free and MIT licensed. The code is public, so anyone can read it.

Questions

Is it really free?

Yes. The app costs nothing and the code is under the MIT license. An AI brain is optional and is billed by the provider you choose (Gemini has a free tier; Claude and OpenAI are paid).

Why does Windows warn me when I run the installer?

The installer is not code-signed yet, so SmartScreen does not recognise it. Choose More info, then Run anyway. The source is public in the GitHub repository.

Do I need AI or an account?

No. Peak is lovable without any AI and there is no account. If you add your own key, it can also chat and remember a few things about you.

Does it work on Mac or Linux?

Not yet. It is Windows 10/11 only for now. A macOS port is on the roadmap.

How do I get updates?

Peak can update itself: install automatically when you are idle, ask first (the default), or never check. You can also download any release from this page.
